# 사극 복식 레퍼런스

한국 사극 복식과 장면 자료를 시대, 신분, 복식, 동작 키워드로 찾아 보는 레퍼런스 스튜디오입니다.

검색은 Google 이미지 검색(SerpApi)으로 하고, 검색 버튼이나 검색창 Enter를 눌렀을 때만 실행됩니다. 결과에서 3D 포즈와 비교하고, 고른 자료를 라이브러리에 저장할 수 있습니다.

## 실행

Node.js가 설치된 상태에서 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

검색을 쓰려면 프로젝트 루트에 `.env.local`을 만들고 서버 키만 넣습니다. 이 파일은 Git에 올리지 않습니다.

```
SERPAPI_API_KEY=발급받은키
```

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run start` | 빌드 결과 실행 |
| `npm run lint` | 린트 |
| `npm test` | 단위 테스트 |

## 화면

- `/` 검색, 필터, 즐겨찾기, 3D 포즈, 사람 감지, 자료 뷰어
- `/library` 저장한 자료, 폴더, 메모

검색 유형 `전체`는 일반 복식·유물·인물 자료입니다. `사극 장면`은 드라마·영화 장면 자료를 더 찾도록 서버에 보내는 검색어에만 문맥을 붙입니다.

## 로컬 데이터

라이브러리, 즐겨찾기, 검색 캐시, 포즈 프리셋, 업로드 이미지는 이 컴퓨터의 `data/`와 `storage/`에 있습니다. `.gitignore`에 들어 있어 저장소에 포함되지 않습니다.
